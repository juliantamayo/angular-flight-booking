# Responsive Design

## Defaults

- Write mobile-friendly layouts by default.
- Use existing breakpoints before introducing new ones.
- Keep fixed-format UI stable with grid tracks, minmax constraints, and predictable button dimensions.
- Ensure text does not overflow buttons, cards, summaries, or form fields.

## Current Patterns

- App shell collapses header/footer actions below `42rem`.
- Search form stacks below `58rem`.
- Route and date fields stack below `38rem`.

Follow those patterns unless the component needs a different behavior.
